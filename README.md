# Coin-Op

Releases of Coin-Op: pay-per-use access to servers, settled on the Xelis network.

This repository holds only what you need to install and verify a release: the
install script, the license notices, and the release assets. The first alpha
release is on its way; nothing here is ready to install yet.

Every release's `SHA256SUMS` is signed with the Coin-Op release key and
notarized by Authen; `install.sh` checks both before anything runs.
